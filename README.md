# Linux Security Labs

Hands-on labs focused on securing and hardening Linux systems: firewalls, access control, and service hardening. Built in an isolated VMware lab (Ubuntu Server, Kali Linux, and a router VM).

## Labs

| Lab | Focus | Skills |
|---|---|---|
| [nftables Firewall](nftables-firewall) | Host firewall & attack testing | nftables, nmap, Kali, journalctl |
| [SSH Hardening](ssh-hardening) | Securing the SSH service | SSH, Linux, auth |
